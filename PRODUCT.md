# Product

## Register

product

## Users

React developers, design-system maintainers, and agent-platform teams evaluating or integrating first-class agent interfaces. They need to understand Fraym's components, states, composition patterns, and driver contract by interacting with real examples.

## Product Purpose

Fraym is an open source React UI kit for coding agents. It provides reusable agent surfaces behind a typed driver contract. Its showcase should make every public capability easy to discover, inspect, try, and copy into a product.

## Brand Personality

Precise, composable, credible. Fraym should feel technically serious and quietly distinctive, with clear language and confident defaults.

## Anti-references

Generic admin templates, decorative AI-workflow dashboards, documentation pages made from repetitive cards, and developer scratchpads that expose components without realistic states or usable examples.

## Design Principles

- Dogfood the public API so the showcase proves the kit works.
- Show behavior, not static claims.
- Keep examples copyable and production-minded.
- Use hierarchy and density to support scanning.
- Let the component system carry the brand consistently.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Preserve keyboard navigation, visible focus, semantic structure, sufficient contrast, reduced-motion behavior, responsive layouts, and meaningful labels for interactive controls.
