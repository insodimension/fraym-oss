## Purpose

The kitchen sink is the interactive catalog for every public Fraym token, element, and feature. Its typed entry registry drives searchable navigation, live prop controls, generated JSX, copyable examples, and props reference tables. Theme and accent controls rewrite the same document-root semantic tokens consumed by the catalog and its demos. Every entry also includes a replayable demo dock that streams a contextual `AgentEvent` fixture through `createReplayDriver` and renders the live component inside the session.

## Run locally

From the repository root, run `bun run dev:sink`.
