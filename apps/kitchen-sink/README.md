## Purpose

The kitchen sink is the interactive catalog for every public Fraym token, element, and feature. Its typed entry registry drives searchable navigation, live prop controls, generated JSX, copyable examples, and props reference tables. Theme and accent controls rewrite the same semantic tokens consumed by the catalog and its demos, so every entry doubles as a runtime theming test.

## Run locally

From the repository root, run `bun run dev:sink`.
