# @fraym/aethr

A cinematic companion presence with an imperative canvas engine and declarative
guided scenes.

## Contents

- [Presence](#presence)
- [Cinematic text](#cinematic-text)
- [Wizard](#wizard)

## Presence

`Aethr` maps emotional state, maturity, recession, and quality inputs onto the
canvas engine. The engine can also be used directly.

## Cinematic text

`CinematicText` provides the reserved companion-voice treatment.

## Wizard

`CinematicWizard` renders a JSON-serializable, capability-aware scene graph and
reports host actions without embedding side effects in the specification.
