## Contents

## Purpose

`@fraym/ui` is the React component library for Fraym's reusable agent surfaces.

## Foundation

The package exposes dark-first CSS custom-property tokens, typed token references, composable primitives, and an event-driven `Thread` that consumes `@fraym/driver` streams.
